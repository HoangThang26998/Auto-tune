# Hướng dẫn sử dụng Bộ Plugin HT Audio 98

Chào mừng bạn đến với bộ plugin chuyên nghiệp **HT Audio 98**!

## 1. Thành phần bộ Plugin
- **Auto-Key:** Công cụ dò tông tự động, dò nhịp (BPM) và tự động gửi thông tin sang Auto-Tune.
- **Auto-Tune 11 Pro:** Công cụ chỉnh tông thời gian thực (Zero Latency), hỗ trợ thang âm Dorian và tạo bè 4 giọng (Harmony Player).

## 2. Tính năng nổi bật
- **Zero Latency:** Hát live không độ trễ nhờ thuật toán TD-PSOLA.
- **Smart Key Lift:** Tự động lên tông ở cuối bài hát để tăng sự hưng phấn.
- **Dorian Scale:** Hỗ trợ đầy đủ các thang âm âm nhạc hiện đại.
- **Auto-Send:** Đồng bộ hóa tông giữa Auto-Key và Auto-Tune chỉ trong 1 giây.

## 3. Cách cài đặt (Dành cho bản Build)
### Trên Windows:
1. Copy file `.vst3` vào thư mục: `C:\Program Files\Common Files\VST3`.
2. Mở DAW của bạn (FL Studio, Cubase, Ableton, v.v.) và quét (Scan) lại plugin.

### Trên macOS:
1. Copy file `.vst3` vào: `/Library/Audio/Plug-Ins/VST3`.
2. Copy file `.component` vào: `/Library/Audio/Plug-Ins/Components` (Dành cho Logic Pro).

## 4. Hướng dẫn sử dụng nhanh
1. Chèn **Auto-Key** vào track tổng (Master) hoặc track nhạc cụ chính.
2. Nhấn nút **Auto-Send** để plugin tự động dò và gửi tông.
3. Chèn **Auto-Tune 11 Pro** vào track giọng hát (Vocal).
4. Chọn chế độ **Zero Latency** nếu bạn đang hát live.
5. Tùy chỉnh **Harmony Player** để tạo các giọng bè dày dặn.
